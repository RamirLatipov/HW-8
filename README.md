# Домашняя работа по C#: глава 8 и иерархия сотрудников

В одном решении `Homework8.sln` находится один консольный проект. В основной ветке доступны все задачи через меню. Каждая задача также размещена в отдельной ветке; там проект запускает именно эту задачу.

Запуск из папки репозитория: `dotnet run --project Homework8`. Для сборки нужен .NET SDK 11 (на этом компьютере установлена предварительная версия). В Visual Studio откройте `Homework8.sln`.

Упражнение 8.3 и домашнее 8.1 запрашивают пути к файлам. Если используются относительные пути, они отсчитываются от текущей рабочей папки запуска. Выходной файл будет перезаписан, если он уже существует. Для домашнего 8.1 предполагается одна запись `ФИО # адрес` на строку. Строки без `#` пропускаются.

Банковский счёт учитывает условия упражнений 7.1–7.3: закрытые поля, текущий и сберегательный типы, методы заполнения и чтения данных, автоматический номер, пополнение и снятие.

В модели сотрудников руководители и категории заданы явно. Для сотрудников секторов прямой руководитель — заместитель сектора; у начальников секторов два допустимых руководителя: Оркадий и Володя. Примеры показывают как успешное назначение, так и отказ.
